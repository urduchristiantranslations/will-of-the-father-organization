# The Will of the Father Organization website

A lightweight static website designed for GitHub Pages. It uses plain HTML, CSS, and JavaScript and does not need a build step or paid hosting.

## Before publishing

- The public email address and WhatsApp contact link are included in the site.
- Confirm the donation wording and payment instructions with the ministry. The page invites donors to email for bank-transfer or Western Union instructions; it does not publish account details.
- Review every text and image. The selected images are from the outreach, prayer, and teaching folders. Photos of children were left out until publication permission is confirmed for those specific images.
- Review the statement of faith and confirm it reflects the ministry’s teaching.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `will-of-the-father-organization`.
2. Upload the contents of this folder to the repository’s root (including `index.html`, `styles.css`, `script.js`, and `assets/`).
3. Open the repository’s **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder. Save.
5. GitHub will display the published website address in the Pages settings when the deployment is ready.

GitHub Pages serves the site publicly. Keep private information, account credentials, and personal documents out of the repository. See [GitHub’s official Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
